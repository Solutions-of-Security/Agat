# Сборка MinIO для интеграционного CI

26.09.2026. В [первом CI PR #20](https://github.com/Solutions-of-Security/Agat/actions/runs/36267576348)
проверка `artifact-store` остановилась до запуска тестов: Quay вернул
`unauthorized` при скачивании закреплённого MinIO-образа. Остальные пять jobs
(основные тесты, браузер и три инфраструктурные интеграции) прошли.

[Upstream README](https://github.com/minio/minio#source-only-distribution)
описывает распространение community-версии исходниками.
[Релиз RELEASE.2025-10-15T17-29-55Z](https://github.com/minio/minio/releases/tag/RELEASE.2025-10-15T17-29-55Z)
предлагает сборку из исходников. Поэтому одноразовый S3-стенд теперь собирает
собственный образ перед запуском контейнеров.

В [Dockerfile](../../deploy/minio/Dockerfile) закреплены:

- официальный commit MinIO `9e49d5e7a648f00e26f2246f4dc28e6b07f8c84a`;
- SHA-256 архива исходников `45521908307306e925c98d629e1c17d78c8b72b6ee242b1bfb1409f7d8ee5841`, проверяемый Docker при загрузке;
- официальный Go `1.27.1-bookworm` с digest `sha256:69a7b9788769bec032d238959b61854e9ae87f57be9029ec04e9885fabf99195`;
- upstream `go.mod`/`go.sum`: `go mod verify`, `-mod=readonly` и отключённая автоматическая смена toolchain.

Это сборка Agat для интеграции, а не опубликованный бинарный релиз MinIO.
Итоговый scratch-образ содержит сервер, CA certificates и исходную лицензию.
Первый вариант работал под UID/GID 10001 с отключённым самообновлением. Image labels
содержат исходный репозиторий, commit и релиз. Архив и toolchain закреплены;
побитовая воспроизводимость бинарника между платформами отдельно не заявляется.

Команда остаётся прежней:

```bash
npm run fleet:test-artifact-store
```

[Скрипт](../../scripts/test-s3-artifact-store.sh) собирает локальный образ,
поднимает PostgreSQL и MinIO с одноразовыми данными и проверяет настоящие
S3-операции. Порты привязаны к loopback; контейнеры и сеть удаляются обработчиком
EXIT. Сборочные слои и образ остаются в локальном Docker cache для повторных
прогонов. Образ в registry не публикуется. Первая сборка требует доступа
к Docker Hub, GitHub и публичным Go modules; ошибка загрузки или checksum
останавливает проверку.

Локальная проверка на Apple Silicon / Docker 29.8.0: сборка Go 1.27.1,
проверка всех Go modules и `fleet:test-artifact-store` — pass, 1/1 integration,
0 skipped. Проверены миграция BYTEA, чтение cache другой репликой, изоляция
outbox и удаление конкретной S3-версии. `bash -n` и Markdown link checker
также прошли. Итог Linux CI привязан к SHA PR и проверяется отдельно.

Первое изменение относилось к CI-стенду. Следующий этап перенёс общий Dockerfile
в `deploy/minio`, установил UID/GID 1000 для совместимости с локальным PVC
и подключил сборку в Docker Desktop: [отдельный протокол](./2026-09-26-local-minio.md).
Историческая [проверка 1.7.0](./1.7.0-validation.md) сохранена как свидетельство своего запуска.
