# Первый результат: заметка → краткий отчёт

Сценарий для public preview 1.7.0. Нужны coordinator, Ollama и Python worker из
[быстрого запуска](./README.md#быстрый-запуск) или [Docker-руководства](./local-docker.md).
Web-поиск, embeddings и внешние инструменты для примера не нужны.

## Проверить готовность

Откройте `http://127.0.0.1:8787` и **Администрирование → Узлы**.
Worker должен быть online и публиковать модель `llama3.2:latest`.
Если используете другой порт или модель, замените их в командах и форме агента.

## Создать помощника

Откройте **Создание → Агенты → Новый агент**:

| Поле | Значение |
| --- | --- |
| Имя агента | Первый помощник |
| Роль | Кратко пересказывает рабочую заметку |
| Инструкция агента | Перескажи входную заметку в трёх кратких пунктах на русском языке. Сохрани все числа и сроки. Не добавляй отсутствующие факты. |
| Модель | `llama3.2:latest` |
| Способ выполнения | Один агент · модель и инструменты |

Нажмите **Создать агента**. В каталоге появится помощник с доступным узлом.

## Запустить задачу

Нажмите кнопку запуска в строке помощника. Название: **Итоги работы команды**.
Вставьте входной текст:

```text
Команда получила 12 заявок. Девять уже завершены.
Три заявки требуют согласования до пятницы.
Подготовь краткий итог для руководителя в трёх пунктах.
```

Нажмите **Далее: цепочка**, проверьте, что выбран только **Первый помощник**,
затем **Далее: проверка → Запустить**. Оставьте сохранение результата в журнал.

По умолчанию включено ручное подтверждение. В карточке появится **Требует решения**:
проверьте входной текст и нажмите **Разрешить продолжение**. После этого worker
выполнит задачу. Пока подтверждение не получено, ожидание является нормальным состоянием.

## Проверить результат

Откройте карточку в **Запусках**. Ожидаемый статус — **Завершён**.
Ответ должен сохранять 12 полученных заявок, 9 завершённых, 3 ожидающих согласования
и срок «до пятницы». Формулировки зависят от модели. Пример ожидаемого ответа:

```text
• Команда получила 12 заявок.
• Девять заявок завершены.
• Три заявки необходимо согласовать до пятницы.
```

Это критерий результата, а не заранее записанный ответ приложения. В карточке
доступны ответ этапа и журнал. После обновления страницы ответ должен сохраниться.

Фактический ответ локальной модели, снимок интерфейса и условия проверки —
в [протоколе public preview](./releases/1.7.0-validation.md).

| Симптом | Что проверить |
| --- | --- |
| Запуск остаётся в очереди | Worker online; имя модели в агенте совпадает со списком узла |
| Требует решения | Проверьте карточку согласования и разрешите продолжение |
| Worker не подключается | URL coordinator и enrollment token совпадают; в терминале нет ошибки регистрации |
| Ошибка модели | Ollama работает; `ollama list` содержит модель; endpoint доступен worker |
| Открывается другой сервис | Порт `AGAT_PORT` / `AGAT_HTTP_PORT`; ответ `/api/v1/health` |
| Ответ искажает числа | Журнал и настройки модели; завершённый запуск ещё не подтверждает качество ответа |
