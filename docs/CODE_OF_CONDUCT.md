# Правила общения

Участники АГАТ общаются уважительно независимо от опыта, происхождения, идентичности
и убеждений. Критикуйте конкретное решение и приводите воспроизводимые примеры.
Учитывайте разные языки и часовые пояса участников.

В issues, pull requests и других пространствах проекта недопустимы оскорбления,
угрозы, преследование, дискриминация, сексуализированное общение, спам и публикация
чужих персональных данных без согласия. Правила распространяются также на публичное
представление проекта его участниками.

Сопровождающие могут попросить скорректировать сообщение, скрыть нарушающий правила
контент, ограничить обсуждение или доступ участника. Решение зависит от тяжести
и повторяемости поведения; техническое разногласие само по себе не нарушение.

По вопросам модерации создайте issue без персональных сведений. Для конфиденциального
сообщения о нарушении правил GitHub используйте **Report abuse** на соответствующей
странице: такое обращение получает GitHub Support. Не публикуйте чувствительные
детали в открытом обсуждении. Уязвимости ПО направляйте по [Security policy](./security.md).
