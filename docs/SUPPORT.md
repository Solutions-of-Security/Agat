# Поддержка

- **Начать работу:** [первый результат](./first-run.md), [Docker Compose](./local-docker.md), [оглавление](./index.md).
- **Ошибка:** [создать bug report](https://github.com/Solutions-of-Security/Agat/issues/new?template=bug_report.yml).
- **Предложение или вопрос:** [создать обращение](https://github.com/Solutions-of-Security/Agat/issues/new?template=feature_request.yml).
- **Уязвимость:** [приватная форма](https://github.com/Solutions-of-Security/Agat/security/advisories/new) и [Security policy](./security.md).

Укажите tag/commit, способ запуска, ОС, версии Node/Python/Docker, шаги и ожидаемый
результат. Прикладывайте минимальные обезличенные данные и журнал без токенов,
паролей, рабочих документов и персональных данных. `.env` публиковать не нужно.

Проект сопровождает [Solutions-of-Security](https://github.com/Solutions-of-Security).
Public preview поддерживается по мере доступности команды; гарантированный срок
ответа и production SLA не заявлены. Перед новым issue проверьте существующие обращения.
