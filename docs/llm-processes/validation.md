# Проверка анализа, требований и шаблонов

Дата: 11.09.2026. Проверяется поставка каталога и создания черновиков, а не production-допуск 13 бизнес-процессов.

## Среда и воспроизводимость

Исходники: рабочее дерево Agat поверх `de27ed0`. В исходном `node_modules` обнаружены файлы с флагом macOS `compressed,dataless`; их чтение задерживало запуск. Для проверки использована отдельная копия в `/tmp/agat-llm-processes-qa` с зависимостями из того же `package-lock.json` (`npm ci --ignore-scripts`). Рабочая БД и существующий Docker-стенд не изменялись. Изменённые файлы кода/тестов сверены с временной копией побайтно.

Node.js v25.8.0, TypeScript 7.0.2, Vite 8.2.1. HTTP/UI: временный coordinator `127.0.0.1:18787`, SQLite, отдельный каталог артефактов, без реального LLM-worker, OIDC и Temporal. Для браузера использован Playwright с установленным Chrome в headless-режиме: **Browser plugin not available**. Браузер и loopback-тесты запускались с разрешением на локальное взаимодействие.

Всего 11 новых тестов. Внутри параметризованных проверок выполнены **26 полных прохождений**: все 13 графов с принятием и все 13 с отклонением результата. Ответы worker подставлялись детерминированно и явно помечены SIMULATED.

Проверено:

- все 13 графов проходят строгую валидацию и публикацию после назначения ролей;
- задания содержат исходный вход, предыдущий результат и предметные критерии;
- без назначений можно создать и скопировать draft, но нельзя его опубликовать/запустить;
- изменение копии не меняет исходный шаблон и повторно полученный каталог;
- неизвестная роль, чужой частный агент, неверная версия и конфликт источников отклоняются до создания;
- HTTP mutation требует admin token в тестовом local auth; создание остаётся внутри выбранного проекта;
- `process.created` содержит ID/версию каталога и категорию;
- после этапов агента состояние — `waiting_approval`, финального process artifact ещё нет;
- принятие даёт `completed` и правильный артефакт; отклонение — `cancelled`, без финального process artifact.

## Проверка в браузере

Проверяемый путь: **Процессы → Новый процесс → категория/поиск → выбор шаблона → назначения → создание → редактор**. Дополнительно: сохранение неназначенного черновика как шаблона проекта и создание независимой копии через UI.

| Проверка | Результат |
|---|---|
| Адрес/заголовок страницы | `http://127.0.0.1:18787/#processes`, «АГАТ — Агенты и процессы» |
| Непустой интерфейс / отсутствие framework overlay | Пройдено |
| Категории, поиск и пустая выдача | 13 → 2 документа → 0 по отсутствующему запросу → 1 договор |
| Назначения и повторный выбор той же карточки | Назначения сохраняются, POST возвращает 201 и draft v0 |
| Создание без назначений и копирование через шаблон проекта | Обе операции проходят в UI |
| Клавиатура | Tab переводит фокус с категории в поиск, Escape закрывает диалог |
| Desktop / mobile | Проверены 1440×1000 и 390×844, сохранены снимки |
| Ошибки JavaScript/console | В пройденном сценарии отсутствуют |

Визуальная перепроверка выявила конфликт со старым mobile bottom-sheet стилем: новый диалог смещался влево. Для него заданы собственные поля, рамка и выравнивание; добавлена проверка координат и горизонтального переполнения. Размер текста «Сохранить как шаблон» увеличен до читаемого значения.

Временные evidence-файлы: `/tmp/agat-process-ui-check.json`, `/tmp/agat-process-catalog-desktop.png`, `/tmp/agat-process-catalog-mobile.png`; сценарий: `/tmp/agat-process-ui-check.cjs`. Эти файлы служат evidence текущего локального прогона, не входят в приложение.

## Сверка документации и границы доказательств

Проверены синхронность каталога, уникальность ID, ссылки и `git diff --check`. Архитектурный аудит (`--profile generic --allow-placeholders`) проверил 6 Markdown-файлов: **0 ошибок, 0 предупреждений**. Заполнители допустимы только в явной заготовке паспорта и учебных примерах. Mermaid-схема из анализа отрисована Mermaid 11.12.0 и визуально просмотрена: подписи и направления связей читаемы; временный снимок — `/tmp/agat-process-flow.png`. Итоговые 15 изменённых файлов кода/тестов/генератора побайтно совпадают с проверенной копией. Все деловые описания, требования и руководство находятся в `/docs`.

Состав сверяется с запросом: анализ AS-IS/TO-BE и baseline; 7 категорий с правилами отнесения; 13 паспортов с участниками, этапами, входами/результатами и исключениями; общие/предметные требования; готовые графы, UI/API и шаблон для расширения.

**Не проверено этими тестами:** качество реальной модели, доменная истинность ответов, end-to-end RAG на фактических источниках, внешние коннекторы/операции, OIDC-вход в данном UI-прогоне, PostgreSQL HA, реальные устройства/screen reader и эффект пользовательского пилота. Существующие unit/contract-тесты этих механизмов не равны испытанию конкретного production-контура. Владельцы и условия закрытия этих gates перечислены в [анализе](./analysis.md#to-be-и-переход) и [требованиях](./requirements.md).

Существовавшие до задачи изменения в `agent-marketplace.md`, `roadmap.md` и исследовании использования сохранены. Новый каталог не объявляет roadmap solution packs полностью выпущенными. Deployment в рабочий стенд в эту проверку не входит.
