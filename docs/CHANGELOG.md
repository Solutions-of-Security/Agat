# История публичных поставок

## 1.7.0 — public preview

Первая версионированная публичная поставка после первоначального опубликования
исходников 17 сентября 2026 года. Состав, ограничения, проверки и обновление описаны
в [release notes](./releases/1.7.0.md).

В эту поставку входят оформление GitHub, первый воспроизводимый сценарий,
универсальная подготовка Compose-конфигурации, правила участия, проверка ссылок,
браузерный smoke и PostgreSQL/S3 CI jobs.

Более ранние номера в [истории реализации](./roadmap.md#история-реализации) обозначают
внутренние этапы разработки, а не отдельные опубликованные GitHub Releases.
Будущие возможности и незакрытые gates остаются в roadmap.
