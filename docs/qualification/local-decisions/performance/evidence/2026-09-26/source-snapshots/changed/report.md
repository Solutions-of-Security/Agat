# Расчёт операционных показателей

Исходные данные [requests-P1]: 3 заявок, 4.5 ч обработки, 1 отклонений.
Исходные данные [requests-P2]: 2 заявок, 3 ч обработки, 1 отклонений.

| Показатель | 2026-07 [requests-P1] | 2026-08 [requests-P2] | Изменение |
|---|---:|---:|---:|
| Число заявок | 3 | 2 | -33.333% |
| Общее время обработки | 4.500 ч | 3.000 ч | -33.333% |
| Среднее время на заявку | 1.500 ч | 1.500 ч | 0.000% |
| Доля отклонений | 33.333% | 50.000% | +16.667 п.п. |

Отображение округлено до 3 знаков после запятой; точные значения сохранены в расчётном JSON.
Среднее время = часы обработки / число заявок. Доля отклонений = заявки с отклонением / все заявки × 100%.
Изменение в процентах = (новое − прежнее) / прежнее × 100%; процентные пункты — разность двух долей в процентах.

При нулевом числе заявок среднее и доля не определены; относительное изменение от нулевой базы также не определено.
Причины изменений по этим данным установить нельзя. Расчёт не подтверждает полноту и достоверность исходных записей.

## Расчёт по отдельным заявкам

Источник: `urn:agat:request-records:authored-diagnostic`. SHA-256 исходных байтов: `415e50c48ea67ecb2c9ee939c395ce74ee49a9ac6d5ada991a8f99a40252e24b`.
Выбраны строки 2–9 включительно, считая с 1; границы байтов: [28, 186).

Строк данных: 7; уникальных пар «период + ID заявки»: 5; одинаковых повторов исключено: 2.
Ключ дубля — период и ID заявки. Часы сравниваются как точные числа (1 и 1.0 равны), признак — как 0 или 1. Конфликтующие дубли останавливают расчёт; значения не выбираются по порядку строк.
ID сравниваются посимвольно с учётом регистра: 001 и 1 различаются. Один ID в разных периодах учитывается в каждом периоде.

| Группа | Период | Строк данных | Уникальных заявок | Исключено повторов |
|---|---|---:|---:|---:|
| requests-P1 | 2026-07 | 4 | 3 | 1 |
| requests-P2 | 2026-08 | 3 | 2 | 1 |

| Поле | Столбец источника |
|---|---|
| period | `period` |
| requestId | `request_id` |
| processingHours | `hours` |
| hasException | `reopened` |

Совокупность, заявленная в mapping: `authored-request-periods`.
«Отклонения» означают заявки со значением 1 в столбце `reopened`; знаменатель — все уникальные заявки периода.
Каждая строка должна содержать полные часы заявки за период и один булев признак; периоды должны быть сопоставимы. Это декларации mapping. События и отдельные интервалы работы требуют другого расчёта.
Проверены исходные байты, выбранные ячейки, дубли по заданному ключу и арифметика. Полнота выгрузки, достоверность, смысл ID и принадлежность одной совокупности не подтверждены.
Расчётный JSON содержит все исходные строки с byte offsets, SHA и ссылками duplicateOf на учтённую запись.
