# Выбор закреплённого resident профиля

05.10.2026 MSK. **Builder/manager принимают выбранный public profile,
пакет 0.12.3 с wired budget 4096 МиБ подготовлен и независимо проверен.**
Действующие jobs остаются на 0.12.2. Подготовка нового пакета не является
его native launch/recovery gate или постоянным rollout.

## Привязка recipe

[Builder](../../../../scripts/prepare-decision-resident-deployment.py)
принимает `--profile`: committed JSON под public `docs`, по умолчанию
[текущий профиль без explicit wired setter](./profiles/runtime-0.12.3.json).
Canonical path, полный profile fingerprint, policy и source SHA проверяются
до копирования модели. Private/outside paths и symlink escape отвергаются.
Selected source path сохраняется в sealed bundle как `profileSourcePath`;
его bytes должны совпадать с указанным source commit.

Resident recipe сохраняет max input 2048, cache 128 МиБ, isolated spawn,
deadline 5000 мс и uncalibrated temperature 1. Wired bytes, если поле задано,
должны быть целым числом МиБ в CLI range. Recipe различает отсутствие
setter, explicit 0 и положительный budget. Остальные ресурсы/пороговые
настройки не выводятся произвольно из profile.

[Manager](../../../../scripts/manage-decision-resident-deployment.py)
проверяет выбранный source, скопированный profile и точный argv обоих jobs.
Отсутствие `profileSourcePath` в прежнем sealed bundle означает исторический
0.12.2 source, поэтому существующая регистрация остаётся управляемой.
Native read-only проверка на commit
`9662f9d1597e06221e81ad35b46ca157b7b594b2` подтвердила прежние bundle bytes,
registration/plist ownership, точный ready profile и свежий scrape.

```bash
# Новый output и новый release directory; подготовка ещё не запускает jobs.
python scripts/prepare-decision-resident-deployment.py \
  --destination "$HOME/Library/Application Support/Agat/decision-shadow/releases/<new-release>" \
  --python /absolute/path/python-3.13.12 \
  --manifest /absolute/path/resident-model.json \
  --wheelhouse /absolute/path/pinned-wheels \
  --prometheus /absolute/path/prometheus \
  --promtool /absolute/path/promtool \
  --profile docs/qualification/local-decisions/performance/profiles/runtime-0.12.3-wired-4096.json \
  --output docs/private/<new-run>/preparation.json
```

`776fba7fa1244e13292ac3605a53a6d6c6cf557901c8d863cab9489d6d2f47ce`.

`2f2faa7cbce6bdf5df20c86f5d2109cf8ac8fe58277b3a99c526bd215be1c5c2`.

оставшегося пространства. Старый release сохранён для rollback.

Закреплены 28 source files, 41 различный copied/generated file, 34 wheels
и 34 installed dependencies. Все шесть preparation commands завершились
с exit 0: новый venv, offline hash install, `pip check`, малый MLX/Metal
calculation, promtool config и rule tests. Модель, model card и лицензии

Независимый verifier повторно пересчитал historical/current source SHA,
все copied/generated bytes, model artifact, exact wheel metadata/hash lock,
pins и оба plist recipes. Новый bundle не зарегистрирован. Прежние два
jobs сохранили PID, profile и свежий scrape. Полные manifest, host paths,

[public summary](./evidence/2026-10-05/resident-profile-preparation-0.12.3/result-summary.json)

(четыре прежних opt-in skips), 12 Node checks, local links и process catalog.
Первый ограниченный запуск целевых tests отказал на loopback socket;
повтор с native доступом прошёл.
