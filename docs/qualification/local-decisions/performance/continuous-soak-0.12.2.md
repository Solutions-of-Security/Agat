# Двухчасовая непрерывная нагрузка runtime 0.12.2

04.10.2026. **Полный план 7200 секунд выполнен без ошибок** после
[исправления HTTP admission](./http-admission-release.md). Один runtime
и один изолированный inference process обслужили восемь последовательных
блоков без restart и retry. Автоматическая маршрутизация выключена;
предметная qualification не оценивалась.

## Профиль и метод

Измеренный и анализируемый commit —
`94e8f65e9b3e8995948c2cdc3d0daec2452cca9f`, merge
[PR #112](https://github.com/Solutions-of-Security/Agat/pull/112).
Перед запуском заморожены SHA 49 файлов и полный
[профиль 0.12.2](./profiles/runtime-0.12.2.json):
`81663153638983bd72afd5a31d8871f38c7db064e28a37636a36b780cf0b6cef`.
Resident decider-2b, pinned revision и MLX dependencies, policy,
2048 input tokens, cache 128 МиБ и isolated deadline 5000 мс совпали
с опубликованным экспортом. Восстановление окружений и весов выполнено
до опыта и не входит в измеряемый интервал.

[Метод и инструменты](./continuous-soak.md) используют concurrency 1,
15 ранее одобренных development Choice/Boolean-входов, три отдельных
warmup перед первым блоком и блоки по 900 секунд. Один sampler проверяет
готовность, профиль и идентичность собственных процессов во всём опыте.
Первый отказ или изменение решения прекращает нагрузку. Каждая observation
сохраняется немедленно; flush не является гарантией сохранности при потере
питания. SHA фиксируют содержимое, а не являются цифровой подписью.

## Независимая перепроверка

[Verifier](../../../../scripts/verify-decision-soak.py) прочитал исходники
из измеренного Git commit, пересчитал seals плана, восьми блоков и launcher,
сверил весь observation journal, длительность, request/result bindings,
профиль, повторяемость и process identity. Результат — `pass`.
[Публичная сводка](./evidence/2026-10-04/continuous-soak-0.12.2/result-summary.json)
экспортирована штатным source-bound summarizer после повторной полной
проверки; в неё входят counts, durations и fingerprints. PID, сведения
о хосте, resource counters и тексты входов в неё не входят.

Launcher остановил собственный runtime, inference child и resource tracker.
Cleanup errors и оставшихся собственных PID нет. После launcher отдельная
проверка существования всех трёх наблюдавшихся PID также подтвердила их
отсутствие. Полная приватная копия evidence сохраняется в `/docs` основного
пользовательского checkout; его прежние изменения исходников сохранены.

Перед опытом на измеренных исходниках прошли полный runtime набор
(125 tests, три opt-in skips), docs/scripts (12 Node и 466 Python tests,
четыре прежних skips), build, typecheck и Temporal history replay.

## Граница и следующий gate

Это двухчасовая проверка одного локального decider на общей машине с
повторением development-входов. Она не измеряет предметную accuracy,
калибровку, независимый holdout, generator/embedding нагрузку, SLO или
надёжность после login/reboot. Длительная нагрузка и наблюдение ресурсов
соответствуют [руководству k6 по soak testing](https://grafana.com/docs/k6/latest/testing-guides/test-types/soak-testing/);
конкретный двухчасовой бюджет был выбран в плане этого проекта.

[Следующий полный Temporal/PostgreSQL/RAG](./temporal-runtime-0.12.2.md) с тем же профилем 0.12.2,
контролируемым отказом и restart shadow, обоими embedding transport и
отдельным native replay после cleanup выполнен 04.10. Прежний внеплановый exit 75 при
совместно загруженных моделях остаётся открытым вопросом; standalone успех
и fix HTTP admission не устанавливают его причину.
