# Целостность исходников терминального review

CLI фиксирует 14 локальных Python-файлов: входной скрипт, его статические
транзитивные импорты и initializer пакета. Раньше registry содержал семь файлов
и пропускал семь зависимостей. Регрессионный тест вычисляет текущие локальные
импорты из AST и сверяет их с registry. Динамические импорты и внешняя среда
этим тестом не измеряются.

Перед стартом и сохранением working bytes каждого зарегистрированного файла
должны совпасть с committed bytes. Во время сессии сравнивается SHA-карта кода.
Коммит документации с прежними bytes кода допускается; изменение зависимости
прерывает сессию до сохранения предложенного ответа. `sourceCommit` квитанции
сохраняет исходный snapshot, а `sourceFiles` позволяет проверить его код.

Это соответствует модели Git: commit фиксирует дерево, а сравнение двух деревьев
можно ограничить путями. Изменение всего дерева само по себе не означает изменение
конкретных исходников. Основание: [Git objects](https://git-scm.com/book/en/v2/Git-Internals-Git-Objects)
и [git diff](https://git-scm.com/docs/git-diff).

## Проверка через настоящий CLI

[Сводка](./blind-terminal-source-integrity-summary.json), source commit
`7045e4463d444d8f6a1c7f04b3ebfb293ca43615`. В отдельном owned Git-репозитории
находились только 14 зарегистрированных Python-файлов и синтетическая документация.
`--help` прошёл без соседнего checkout. Две сессии выполнялись через настоящие PTY:

- После первого prompt родитель изменил и закоммитил только документацию.
  Один синтетический ответ сохранился; exit 2, partial, два пустых задания,
  `reviewedAt=null`. Квитанция сохранила исходный commit и все 14 SHA.
- После первого prompt второй сессии родитель изменил и закоммитил одну
  транзитивную зависимость. CLI завершился с exit 1 и failed-квитанцией.
  Предложенный ответ не попал в checkpoint; все три задания остались пустыми.

Синтетическое Git bundle сохраняет три snapshot и позволяет независимо проверить
точный diff обоих коммитов. Независимый аудитор на stdlib и Git реконструировал
2644 проверки / 2477 JSON keys, включая receipts, SHA, статическую closure,
полные input bindings и неизменность protected resident. Он не запускал CLI
повторно и не вызывал модели. Два owned CLI PID отсутствуют после проверки.

Первый запуск контрольного helper был отклонён до plan и PTY: в аргументе оказался
сокращённый SHA. Ошибка подготовки диагностической записи также сохранена;
исправленный запуск использовал полный SHA. Исходные helpers и отказы сохранены. Первый archive helper также остановился
до записи архива из-за пути к preflight-каталогу вместо успешного v2-каталога.
Исправлен только helper; исходные PTY-сессии не повторялись.

43 целевых Python-теста прошли. Полный прогон: 1236 тестов, четыре пропуска,
549.370 s. Публичные 49 development-заданий остаются без меток; предметная точность,
личности и независимость reviewer, квалификация экспертов и SLO не подтверждены.
Resident, production routing и публичные review-пакеты не изменялись.

## Воспроизведение

[Архив и проверки копии](./blind-terminal-source-integrity-archive-summary.json)
содержат исходные PTY transcripts, synthetic fixtures, Git bundle, SHA-карты,
логи тестов, независимый аудитор и committed source snapshots. Восстановление
повторяет аудит исходных квитанций без нового CLI или model execution.

[Исторический этап v2](./blind-terminal-corrections-summary.json) и его архив
сохраняют исходный registry из семи файлов. Эти receipts не переписаны после
расширения registry. Проверка человеческой разметки остаётся следующим
предметным этапом после двух независимых review реальными людьми.
