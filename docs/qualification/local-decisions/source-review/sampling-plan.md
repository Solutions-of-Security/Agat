# Объём независимых групп для qualification

26.09.2026. [Расчёт для blank review v3](./sampling-plan.v3.json) использует текущий seed и **примерные, не утверждённые владельцем** [критерии](../calibration/criteria.example.v1.json). Он не обращается к модели, не читает предложенные ответы и не меняет набор. Это оценка необходимой ёмкости holdout при оптимистичном допущении: все группы приняты и ошибок нет.

В `qualify` применяются четыре односторонних bounds: общий и по трём семействам. При совместном confidence 0.95 Bonferroni даёт confidence каждого bound 0.9875. Для нуля ошибок верхняя граница равна `1 − α^(1/n)`, где `α = 0.0125`, а `n` — число **независимых принятых групп**. Минимальное целое `n` для риска ≤ 0.01 — **437**: для 436 bound равен 0.0100001821, для 437 — 0.0099774129. Точные биномиальные границы описаны в [документации SciPy о Clopper–Pearson](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats._result_classes.BinomTestResult.proportion_ci.html); направление и поправка соответствуют реализации `qualify` в Агат.

Номинальные `minAcceptedGroups: 300` и `minAcceptedGroupsPerFamily: 30` сами по себе не обеспечивают risk gate. В данном примере эффективный минимум — 437 суммарно и 437 в каждом семействе при нуле ошибок. Семейные числа нельзя автоматически сложить: одна группа может содержать несколько семейств. При ошибках требуется больше наблюдений. Case coverage 0.5 также нельзя напрямую использовать как долю принятых групп.

| Область | Потенциальных holdout-групп v3 | Требуется при нуле ошибок | Дефицит даже при принятии всех |
|---|---:|---:|---:|
| Суммарно | 4 | 437 | 433 |
| Evidence | 3 | 437 | 434 |
| Classification | 2 | 437 | 435 |
| Clarification | 3 | 437 | 434 |

Это потенциальные группы до экспертной проверки, а не уже принятые моделью. Даже при безошибочности всех четырёх групп общий optimistic upper bound составил бы 0.66563. Независимость и представительность источников не доказаны; новые ID или перефразы не создают независимых наблюдений.

У v3 также **ноль calibration-групп**. Их достаточный объём зависит от разнообразия вопросов, вариантов и распределения ошибок; приведённая формула относится к holdout risk gate и не определяет размер calibration split. Перераспределять уже выбранные группы или подбирать seed ради заполнения calibration этот инструмент не предлагает. Нужны дополнительные независимо полученные источники и человеческие review.

## Воспроизведение

```bash
python3 scripts/plan-decision-sampling.py \
  --blank-review docs/qualification/local-decisions/source-review/review.first.blank.v3.json \
  --criteria docs/qualification/local-decisions/calibration/criteria.example.v1.json \
  --output docs/qualification/local-decisions/source-review/sampling-plan.new.json
```

Инструмент принимает исходный целый blank-пакет, отвергает внесённые метки и повреждённые привязки, считает группы по прежнему seed и отмечает пересечение source ID между splits. Для нулевого допустимого риска не заявляет конечную достаточную выборку. Непрактичные расчёты свыше миллиарда групп отмечаются отдельно. Существующий output не перезаписывается; `routingEnabled` и `qualifiedForRouting` всегда false.

Семь тестов проверяют аналитическую границу и минимальность целого `n`, поправку для трёх семейств, нулевой риск, предельный объём, неизменность seed/источников, отсутствие labels/inference, отказ для заполненного review, пересечение source ID и невозможность увеличить число независимых групп копированием cases. Параметры принятия решения владельцем не подменяются рассчитанными числами.
