# Проверка и импорт русской формы review

[Подготовка формы](../../../../../scripts/prepare-decision-review-form.py)
принимает исходный незаполненный review и русский перевод с SHA-256 обоих
файлов. Она проверяет исходный вопрос и полные описания пяти категорий,
порядок заданий, исходные input SHA, все абзацы и точное сохранение команд
и журналов. Выходной каталог должен быть новым и находиться в `docs/private`.
HTML содержит код, оформление и данные; CSP запрещает сетевые запросы.

`manifest.json` связывает форму с исходным blank, переводом и четырьмя файлами
интерфейса. `review.blank.json` сохраняет точные исходные bytes. Перевод
меняет представление, сохраняя исходные pool SHA, split seed и input SHA.
Эта привязка проверяет целостность, но не доказывает семантическую
эквивалентность перевода: `translationEquivalenceVerified=false`.

Скачанный файл имеет схему `agat.decision.review-form-export.v1`. Он хранит
русские названия вариантов, обоснования, владельца и текущий вопрос.
Частичный текст сохраняется в черновике. Итоговый файл требует всех ответов,
русских обоснований, имени и отдельного подтверждения завершения. Варианты
по умолчанию отсутствуют. При повторном скачивании итогового файла дата
подтверждения сохраняется; возврат к правке снимает завершение.

Пример технического импорта; SHA берутся от фактических файлов:

```bash
python3 scripts/import-decision-review-form.py \
  --export docs/private/received/answers.json \
  --export-file-sha256 EXPORT_SHA256 \
  --manifest docs/private/prepared/manifest.json \
  --manifest-file-sha256 MANIFEST_SHA256 \
  --input-review docs/private/prepared/review.blank.json \
  --input-review-file-sha256 BLANK_SHA256 \
  --output-dir docs/private/imported-review
```

[Импортёр](../../../../../scripts/import-decision-review-form.py) проверяет
пины, владельца, даты, порядок и русский текст вариантов, затем создаёт
канонический `review.json` с неизменённым исходным пулом. Неполная пара
«вариант + русское обоснование» не становится каноническим решением; исходный
черновой текст остаётся в приложенных bytes выгрузки.

Квитанция `agat.decision.review-form-import.v1` отличается от интерактивной
терминальной session: она сохраняет точные bytes пользовательского экспорта,
его SHA и manifest, а также исходники импортёра из текущего commit.
Код требует их совпадения с Git до создания результата. Обычный
[верификатор](../review-session-verification.md) принимает обе схемы,
сверяет преобразованный review с исходной выгрузкой и проверяет квитанцию.
[Сверка пары](../review-pair-comparison.md) и
[подготовка разногласий](../review-adjudication.md) используют тот же путь
проверки. Старые терминальные квитанции проверяются прежним верификатором.

Имя и явное подтверждение заявлены самим участником. Они не доказывают
личность, квалификацию или независимость. Все authority flags остаются false,
`qualification=not_assessed`, reference labels=0, model calls=0. Проверки
интерфейса выполняются только на синтетических заданиях; реальные ответы
создают пользователь и выбранный им эксперт.
