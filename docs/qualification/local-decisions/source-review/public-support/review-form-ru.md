# Русская форма опроса для двух участников

Для заполнения нужен только файл `review-form.html`. Откройте его двойным
щелчком в браузере. Установка программ и подключение к интернету не нужны.

1. Выберите «Первый участник» или «Независимый эксперт» и укажите имя либо
   псевдоним. Каждый участник получает свою копию пустой формы и заполняет
   её самостоятельно.
2. Прочитайте обращение, выберите один из пяти вариантов и кратко объясните
   решение на русском. Кнопка «Сохранить и дальше» открывает следующий вопрос.
   Можно пропускать вопросы, возвращаться по номерам и исправлять ответы.
3. После всех 49 ответов нажмите «Скачать итоговые ответы» и подтвердите
   завершение. Прикрепите скачанный файл `.json` к чату с Codex.

Вопросы, варианты и пояснения переведены на русский. Названия программ,
команды и точные сообщения об ошибках сохранены как технические цитаты.
Длинное обращение можно развернуть целиком; команды и журналы раскрываются
внутри его текста. Изображения, которых нет в исходном текстовом пакете,
не добавлены.

Форма сохраняет прогресс в браузере. Кнопка «Скачать черновик» позволяет
сохранить отдельный файл в любой момент, даже если ответ ещё не дописан.
Для продолжения на другом компьютере откройте ту же форму и нажмите
«Загрузить черновик». Этой кнопкой можно загрузить и прежний незавершённый
терминальный `review.json`. Если браузер сообщает, что его хранилище
недоступно, сохраняйте прогресс кнопкой скачивания перед закрытием формы.

У каждого участника отдельный прогресс. Не передавайте эксперту свой файл
ответов до завершения его опроса. Передать ему нужно только пустой
`review-form.html`. Если требуется исправить уже завершённый опрос, нажмите
«Вернуться к правке», внесите изменения и скачайте итоговый файл заново.

Файлы собираются локально: кнопка завершения скачивает ответы на компьютер.
Чтобы передать их для обработки, приложите JSON к чату самостоятельно.

Устройство, ограничения перевода и проверки описаны в
[отчёте реализации](./review-form-design.md). Технический импорт в прежний
протокол описан в [проверке формы](./review-form-verification.md).
