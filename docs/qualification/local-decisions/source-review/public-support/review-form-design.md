# Русскоязычная форма: устройство и проверка

Форма заменяет терминальный ввод для двух участников текущего development
review. Один переносимый HTML содержит все задания, оформление и код; установка
и сеть не требуются. Ответы выгружаются в один JSON для приложения к этому чату.
Данные сохраняются отдельно для каждого участника. Скачанный черновик можно
загрузить обратно, в том числе на другом компьютере.

Принятый макет создан встроенным Image Gen и сохранён в приватном пакете
`docs/private/2026-10-10/review-form/concept-ru.png`. Он задаёт белый фон,
системный шрифт, основной текст #101828, вторичный #64748b, акцент #087f72,
тонкие границы #d6dee8, радиус 6 px. Шапка и подвал открытые; слева номера
заданий, справа обращение, пять равнозначных вариантов и обоснование. На узком
экране колонки становятся одной, навигация сворачивается. Основной текст
16 px/1.6; заголовок 32 px, заголовок вопроса 24 px, подписи 14 px.

Разрешённая копия интерфейса: «АГАТ», «Экспертная оценка обращений»,
«49 вопросов. Выберите категорию и кратко объясните решение.», «Участник»,
«Первый участник», «Независимый эксперт», «Ваше имя или псевдоним», «Вопросы»,
«Отвечено … из …», «Какую помощь просит автор обращения?», «Обращение»,
«Ваше решение», пять категорий исходной рубрики в русском переводе,
«Почему вы выбрали этот вариант?», «Назад», «Пропустить», «Сохранить и дальше»,
«Загрузить черновик», «Скачать черновик», «Скачать итоговые ответы».
Для реальных длинных заданий дополнительно необходимы название обращения,
атрибуция источника, пояснение рубрики, раскрываемые технические фрагменты,
сброс отдельного ответа и подтверждение финальной выгрузки. Это функциональные
дополнения к короткому демонстрационному обращению макета.

Смысл и состав рубрики сохраняются. Перевод — отдельное представление с
привязками к исходным SHA, без изменений исходного пула и без готовых решений.
Команды и журналы остаются техническими цитатами. Перевод не заменяет оригинал
и сам по себе не подтверждает эквивалентность измерений на двух языках.

Использованы рекомендации [W3C по длинным формам](https://www.w3.org/WAI/tutorials/forms/multi-page/):
прогресс, переход между шагами, сохранение данных и отсутствие ограничения
по времени. [MDN](https://developer.mozilla.org/en-US/docs/Web/API/Window/localStorage)
указывает, что хранение для `file:` зависит от браузера; поэтому экспорт и
импорт черновика обязательны, а недоступное хранилище явно отражается в форме.

Проверка должна охватывать русский текст, все 49 привязок, клавиатурный ввод,
узкий экран, сохранение после перезагрузки, отдельные состояния участников,
неполный черновик, прежний терминальный JSON, скачивание и обратный импорт.
Тестовые ответы создаются только для синтетического пакета.

## Сверка с макетом

Готовая форма написана на HTML/CSS и небольшом JavaScript без внешних
зависимостей. Макет не встроен как картинка. Для снимков браузер отрисовал
тот же код на синтетических пакетах из 3 и 49 заданий. Скриншоты компьютера
1440 px и телефона сохранены в
`docs/private/2026-10-10/review-form/screenshots-final/` и просмотрены вместе
с принятым `concept-ru.png`.

| Проверяемая часть | Результат сравнения |
|---|---|
| Шапка и заголовок | Сохранены белый фон, надпись «АГАТ», название опроса и загрузка справа |
| Идентификация | Выбор участника и имя находятся в одной строке на компьютере и друг под другом на телефоне |
| Навигация | Сохранены левая колонка, сетка 7 × 7 и выделение текущего номера; добавлены полоса прогресса и переход к пропуску |
| Обращение | Сохранены светлый фон и тонкая рамка; добавлены настоящий заголовок, атрибуция, технические цитаты и разворачивание длинного текста |
| Ответы | Пять одинаково оформленных радиокнопок, без выбранного варианта; русские описания сохраняют полную исходную рубрику |
| Обоснование и действия | Поле под вариантами, второстепенные переходы слева, основная кнопка справа; добавлены счётчик символов и очистка |
| Подвал | Сохранены сообщение о сохранении и две выгрузки; итоговая кнопка активна только после заполнения |
| Цвета и узкий экран | Белый/slate/teal, системный шрифт и радиусы 6 px сохранены; на телефоне одна колонка без горизонтальной прокрутки |

Отступления от короткого демонстрационного текста макета согласуются с
описанными выше функциональными дополнениями. Из-за полного пояснения
категорий, названия и атрибуции обращений форма выше демонстрационного
изображения. На телефоне номера свёрнуты по умолчанию, кнопки располагаются
на всю ширину. Лишняя скрытая ссылка, замеченная на первом полном мобильном
снимке, исправлена; переход с клавиатуры проверен отдельно. Доставляемая форма
содержит все 49 реальных development заданий.

## Проверки результата

12 браузерных тестов прошли на компьютере и телефоне: русский интерфейс,
отсутствие готовых ответов, клавиатура, 49 номеров, раскрытие длинного текста,
скачивание, импорт, перезагрузка, старый терминальный черновик, раздельные
участники, явное завершение, возврат к правке и недоступное хранилище.
86 связанных Python-тестов и 6 тестов состояния JavaScript прошли.
Точные результаты полного набора и проверки CLI сохраняются в приватном
пакете; CI проверяет опубликованный commit перед merge.

Отдельный аудит реального HTML проверил 49 development заданий / 44 группы,
240 русских обычных абзацев и 113 неизменённых технических абзацев, порядок,
исходные SHA, пустые решения, встроенные данные и хэши CSP. Существующий
пользовательский review сохранён без изменений. Снимки и автоматические
ответы относятся только к синтетическим заданиям.

Ограничение инструментальной проверки: in-app browser не разрешает открывать
`file:`. Реальный приватный HTML не публиковался через HTTP для обхода этого
запрета. Интерфейс проверен на отдельном синтетическом HTTP-стенде, а реальные
данные и самодостаточность файла — прямым аудитом. Сохранение для `file:`
зависит от браузера; скачивание черновика остаётся способом переноса и
восстановления при недоступном localStorage. Семантическая эквивалентность
перевода и независимость настоящих участников не подтверждены этими тестами.
