# Фиксация полного профиля до измерений

26.09.2026, runtime `0.8.0`. Новый план `agat.decision.experiment.v2` закрепляет полный raw execution profile **до calibration inference**. Раньше план v1 закреплял веса и tokenizer, а версии runtime, prompt, dependencies, предел токенов, cache и изоляция появлялись только в последующем отчёте. Это позволяло случайно смешать эксперимент с другими настройками исполнения.

## Последовательность

1. `profile` загружает и проверяет локальные веса с выбранными параметрами и сохраняет профиль без inference. Для изолированного backend дочерний процесс закрывается после экспорта.
2. `freeze --runtime-profile PATH` проверяет соответствие manifest и policy, требует raw uncalibrated profile с температурой 1 и сохраняет его копию и SHA в плане v2.
3. `evaluate --split calibration` запускается с теми же параметрами после фиксации плана. `calibrate` проверяет policy, полный model identity, runtime version и профиль каждого результата. Начало должно быть не раньше плана; завершение — не раньше начала и не в будущем. Все timestamps должны содержать часовой пояс.
4. После fit выполняется raw `evaluate --split holdout --reverse-options`. `qualify` проверяет тот же профиль в обоих порядках; holdout должен начаться после плана и fit. Новый gate `execution_profile_frozen` требует v2.

Актуальные команды приведены в [основном протоколе](./README.md#план-fit-и-holdout). Для изоляции добавляйте одинаковый `--inference-timeout-ms`, как и одинаковые предел токенов и cache, к `profile`, обоим `evaluate` и последующему `score`/`serve`.

`freeze` без `--runtime-profile` сохраняет совместимый план v1 для воспроизведения старых экспериментов. Калибровка по нему остаётся доступной при корректной хронологии, но квалификация на runtime 0.8.0 получает failed gate `execution_profile_frozen`. Исторические отчёты не переписываются; пересчёт их gates новой версией намеренно отличается этим требованием.

## Обоснование и ограничения

Практики разделения train/test и одинаковой предобработки описаны в [официальной документации scikit-learn](https://scikit-learn.org/stable/common_pitfalls.html). Из них следует требование проекта: параметры исполнения и критерии нужно выбирать до итоговой оценки, а неподходящий отчёт отвергать. Конкретный формат v2 и проверка локальных timestamps — реализация Агат, а не стандарт scikit-learn.

SHA и timestamps обнаруживают несогласованные локальные артефакты. Они не являются подписью, внешним журналом времени или доказательством отсутствия предварительного просмотра данных. Оператор, способный переписать все файлы и SHA, остаётся доверенной стороной. При некорректном системном времени необходимо исправить часы и выполнить новый опыт, не подгонять timestamps старых результатов.

## Проверки

Runtime suite проверяет изменения cache, deadline, token limit, implementation SHA, runtime version в отчёте или отдельной строке, policy, старое начало, некорректное завершение, fitted profile вместо raw и повреждение SHA профиля. CLI-проверка проходит `profile → freeze → evaluate → calibrate → score/serve` с реальным дочерним CPU-процессом и проверяет его освобождение.

Реальный MLX-прогон и его перепроверка сохранены в [отдельном каталоге](./evidence/2026-09-26-frozen-profile/). Используются прежние синтетические fixtures; это инженерный повтор, не новый независимый holdout. Реальный source-review holdout не затронут.

На Apple M1 Max / 32 ГиБ экспортирован [профиль](./evidence/2026-09-26-frozen-profile/runtime-profile.json) с 2048 токенами, cache 128 МиБ и process deadline 2000 мс. После [плана v2](./evidence/2026-09-26-frozen-profile/experiment.json) выполнены 12 calibration-вызовов, fit, затем 12 синтетических holdout-вызовов в двух порядках — всего 36, без backend errors. Температура `3.1929311809325567` совпала с предыдущим опытом. [Qualification](./evidence/2026-09-26-frozen-profile/qualification.json) прошла новый gate профиля и сохранила `not_qualified`: данных и качества для включения маршрутизации по-прежнему недостаточно.

[Перепроверка](./evidence/2026-09-26-frozen-profile/verification.json) пересчитала fit/gates, проверила каждый профиль, хронологию и SHA файлов. Старый отчёт 0.7.1, изменённый deadline и изменённая runtime version в одной строке отвергнуты. Runtime suite: 88 тестов, 3 необязательных MLX skip; реальные MLX-вызовы выполнены отдельно. Экспорт и оба evaluate завершились с закрытием дочерних процессов; постоянный HTTP-сервер для этой проверки не запускался.
