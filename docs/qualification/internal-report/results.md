Первый запуск обнаружил Temporal SDK 1.22.0 вместо закреплённого в lock-файле 1.24.0: [доказательство FAIL](./evidence/2026-09-20-infrastructure-absent/result.md), код выхода 2. После `npm ci` повторный запуск подтвердил доступность Ollama 0.34.0 и отсутствие Qwen3 8B, embeddinggemma и Temporal: [доказательство FAIL](./evidence/2026-09-20-missing-models-runtime/result.md), код выхода 2. Невыполненные этапы помечены `NOT_RUN`; успешная квалификация не заявлена.

Каждый результат хранит хеши исходников своего запуска. Это позволяет отличать промежуточную проверку требований от последующего полного прогона и не приписывать старому evidence новую реализацию.

## Первый реальный прогон

[Запуск с настоящими моделями и Temporal](./evidence/2026-09-20-report-rubric-fail/result.md) завершился **FAIL, код 1**: пройдены ingestion, все три этапа Qwen3 и проверка цитат обоих источников, но машинный критерий изменения среднего времени на −25% не подтвердился. Согласование, скачивание и восстановление в этом прогоне не выполнялись. Сырые ответы удалены, поэтому нельзя утверждать, была ли причиной ошибка модели или равнозначная формулировка, не распознанная первой версией рубрики.

При перепроверке рубрики найдены и исправлены отдельные дефекты: `+200%` не должно соответствовать `+20%`, а `4.5` — ожидаемым `4` часам. Добавлены проверки границ чисел и тест равнозначной записи «сократилось на 25%». Эталонные числа и требования к цитатам не изменялись. Старое evidence оставлено с исходным `FAIL`.

[Второй реальный запуск](./evidence/2026-09-20-refinement-fail/result.md) также завершился `FAIL`: не подтвердился критерий процентных пунктов; экспериментальная ветка отклонения дополнительно получила `400`, поскольку не передавала обязательную причину отказа. В окончательном harness причина передаётся, а контракт `reject` отдельно проверяется HTTP-регрессией пакета. Чтобы сделать задание воспроизводимым для машинной приёмки, к стандартному вопросу добавлены явные требования к форме вычислений; числовые ответы модели не сообщаются.

[Проверка окончательного gate на недоступных endpoint](./evidence/2026-09-20-final-missing-infrastructure/result.md) специально использует loopback-порт 1: зафиксирован **FAIL, код 2**. Этот негативный запуск не останавливал уже работавшие Ollama и Temporal. Хеши входных файлов совпадают с полным успешным прогоном.

Фактически использованные версии: Ollama 0.34.0, Temporal Server 1.31.2, все Temporal SDK 1.24.0, coordinator 1.7.0, Node v25.8.0, Python 3.14.3, macOS arm64. Qwen3: `qwen3:8b`, 8.2B, Q4_K_M; embeddings: `embeddinggemma`, 307.58M, BF16, 768 измерений. Полные digest моделей и хеши исходников находятся в JSON соответствующего запуска.
