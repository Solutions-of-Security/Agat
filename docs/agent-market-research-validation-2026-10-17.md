## Границы

В этой работе изменяются только Markdown-файлы в `/docs`. Исходный код, модели, runtime и внешние системы не меняются. Новый запуск LLM/Temporal, benchmark конкурентов, человеческий пилот и production qualification не выполнялись. Прежний PASS от 20 сентября остаётся историческим результатом одного синтетического задания с `humanReview=false`.

Первичная инвентаризация выполнена `workspace_inventory.py` без чтения содержимого secrets и без hashing всех файлов. Часть workspace имела macOS `dataless` files; нужные источники подгружены и прочитаны. HEAD получен из `.git/HEAD`/локального ref. Полный `git status` не использован как подтверждение чистоты. Перед изменениями сохранены копии трёх редактируемых прежних документов во временный каталог; существующие изменения `index.md` сохранены.

Проверка ссылок выполнена отдельным детерминированным Python-проходом по изменённым файлам. Попытка импортировать штатный `checkMarkdownLinks` через Node не завершилась при подгрузке зависимостей и остановлена; она не отмечена пройденной. Полный `npm run docs:check`, build/typecheck, runtime и browser tests не запускались: менялась только документация, каталог процессов и программный код не затронуты. Внешние страницы проверялись браузингом при исследовании; работоспособность всех внешних ссылок в будущем и неявные anchors старых документов этим локальным проходом не гарантируются.

Повторная смысловая проверка устранила оставшееся требование CLD-006 для cloud P0 в тексте трека и старую сводку статуса pack. Deterministic validation уточнена до формализуемых расчётов, schema/source IDs и artifact invariants; она не выдаётся за автоматическое доказательство истинности всех claims.

## Содержательная перепроверка

- Сравнение содержит восемь продуктовых предложений, различает SDK/runtime, платформу и прикладной продукт; документы вендора не выдаются за измерение качества.
- Девять научных источников имеют даты и версии; самая свежая выбранная публикация — 04.10.2026. Старый foundational MAST явно помечен 2025 годом. Метаданные принятия на конференции отделены от независимой проверки.
- Для Portable Computer описана ограниченная доступность первичного текста; ошибка прямого fetch не скрыта.
- Код PDF/DOCX и fixed pack не включены в backlog как полностью отсутствующие. Файловый parser и поддержка файлов именно в pack v1 различаются.
- Технический completed, результат автоматической проверки и принятие человеком различаются. Сентябрьские проверки не объявлены свежими.
- Новые задачи имеют source rationale, зависимости, ответственные роли, размер, acceptance evidence и rollback; named owners/capacity не выдуманы.
- Local/cloud gates раздельны; CLD-006 перенесён в P1 во всех текущих таблицах. Минимальные RUN-101/RUN-103 — P0, расширения — P1.
- Qualification runtime, security controls и польза предложенных фич остаются будущими gates. Никакая задача не отмечается выполненной по факту написания плана.
